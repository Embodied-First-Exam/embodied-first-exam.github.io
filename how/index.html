The rules

How a test is marked

What keeps the marks honest

  • A separate marker

    The verifier runs in its own sandbox, without network, and sees only the declared answer or the service’s record.

  • No answer key in reach

    Reference solutions never enter the agent’s container, and upstream experts are removed from the images.

  • Controls

    Doing nothing must score 0, and a full reference solution must score 1.

  • A cheat trial

    Before a suite comes in, an agent is told to pass the verifier without doing the task. Any success blocks the suite until the verifier is fixed.

  • Human review

    A task without a full reference solution is checked by a reviewer who did not write it.

  • Frozen tasks

    A published task never changes. Fixing a scene makes a new task.
